# 筋トレ記録（kintore-log）

iPhoneのホーム画面で使う、シンプルな筋トレ記録アプリです（PWA）。

👉 **アプリ：https://omiso-boy.github.io/kintore-log/**

Safariで開き、「共有」→「ホーム画面に追加」でアプリとして使えます。

## できること
- **記録**：部位（胸・背中・肩・腕・脚・腹・首・その他）から種目を選び、前回の重量・回数が入った行を ✓ 1タップで記録。自重の種目は重量を空欄のまま記録
- **種目の追加**：自由入力した種目は次回から一覧に表示
- **休憩タイマー**：60／90／120秒。✓で自動スタート。画面ロックしてもずれない
- **今日のまとめ**：筋肉の全身図で鍛えた部位を表示、セット数・種目数・時間
- **履歴**：カレンダー表示、部位別の週間負荷（セット数／ボリューム）と直近8週の推移グラフ
- **バックアップ**：CSVで保存・読み込み（Googleドライブなどに保存可能）

記録はiPhoneの中だけに保存されます（外部への送信はありません）。定期的にバックアップしてください。

## 開発
- HTML / CSS / JavaScript（ビルド不要・外部ライブラリなし）
- アプリ本体：`app/`　テスト：`npm test`（Node.js 18以上）
- ローカルで確認：`cd app && python3 -m http.server 8765`
- `main` に反映すると GitHub Actions でテスト後に GitHub Pages へ自動公開
- 開発ルールは `CLAUDE.md`、全体像は `docs/INDEX.md`、作業ログは `docs/WORKLOG.md`
