## 2026-11-14（不具合修正：自重の種目が記録できない）
- 症状：懸垂などで重量欄が「0」に見えるのに✓するとエラー
- 原因：空欄の入力例（プレースホルダー）に「0」を表示していたため、未入力なのに0が入っているように見えた
- 対策：重量が空欄なら自重（0kg）として記録。空欄には「自重」と表示。0kgの記録は一覧・前回・通知・履歴で「自重」と表示（weightLabel）。前回が自重なら行は空欄（＝自重）で用意
- 確認したこと：空欄で✓→自重で記録、加重（5kg）も記録可、翌日の前回表示と行の用意をブラウザで確認。単体テスト30件成功
- 注意：バックアップCSVの読み込みでは空欄の重量は従来どおりエラー（勝手に補完しない）。sw.js の VERSION は v10
