# プロジェクト全体マップ

> どこを見れば何がわかるかをまとめた地図。細かいファイル一覧ではなく、全体像の把握用。

## 概要
iPhoneのホーム画面に追加して使う筋トレ記録アプリ（PWA）。記録は端末内に保存し、CSVでバックアップ・復元する。

## ディレクトリ構成
| 場所 | 内容 |
|---|---|
| `app/` | アプリ本体（このフォルダをそのまま公開すれば動く） |
| `app/lib.js` | 画面に依存しないロジック（入力チェック、並べ替え、前回記録、CSV変換、タイマー計算） |
| `app/app.js` | 画面の処理（入力、表示、保存、バックアップ） |
| `app/index.html` / `style.css` | 画面の構造と見た目 |
| `app/sw.js` | オフライン起動用のキャッシュ。アプリ更新時は `VERSION` を上げる |
| `app/manifest.webmanifest` / `icon-*.png` | ホーム画面追加用の情報とアイコン |
| `.github/workflows/pages.yml` | main への反映時にテスト → `app/` を GitHub Pages に公開 |
| `tests/` | `lib.js` の単体テスト（`npm test`） |
| `CLAUDE.md` / `docs/` | ルール・作業ログ・設計判断 |

## 主な機能
- 種目を選ぶ（記録タブ）：部位タブ（胸・背中・肩・腕・脚・腹・首・その他）→ 種目一覧。最近使った種目が先頭。「＋ 種目を追加」で自由入力した種目は次回から一覧に出る。今日記録した種目はチップで表示
- 種目画面：前回の記録を表示し、前回のセット数・重量・回数を入れた行を用意。✓1タップで1セット記録。値の変更、メモ、行の追加・削除が可能。記録済みセットは×で削除
- 休憩タイマー（記録タブ上部に固定）：60/90/120秒。一時停止・再開・リセット。✓で自動スタート（オン/オフ）。終了予定時刻で計算するので画面ロック・再起動でもずれない
- 履歴（履歴タブ）：日付ごとに折りたたみ表示。各セットを削除可能
- バックアップ（バックアップタブ）：CSVを共有メニュー経由で保存／CSVから読み込み（同じIDは重複追加しない。部位情報から追加種目も復元）。7日以上バックアップしていないと記録タブに通知

## データの流れ
種目画面の行 → `validateSet`（lib.js）で検証 → localStorage `kintore.v1.sets` に配列で保存 → 画面に表示
追加種目は `kintore.v1.customExercises`（`{name, part, createdAt}`）。部位は `partOf()` で 追加種目 → 用意済み種目（`PRESET_EXERCISES`）→ その他 の順に決まる
バックアップ：`toCsv` → 共有メニュー／ダウンロード。復元：`fromCsv` → `mergeSets` → 保存

## データ形式（1セット）
種目は名前で紐づけている（種目名の変更機能はまだない）。CSVは `date,part,exercise,weight,reps,note,id,createdAt`（part列のない旧形式も読み込み可）

`{ id, date: "YYYY-MM-DD", exercise, weight: kg(0〜1000, 0.01単位), reps: 整数(1〜1000), note, createdAt: ISO8601 }`
