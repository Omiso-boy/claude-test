# プロジェクト全体マップ

> どこを見れば何がわかるかをまとめた地図。細かいファイル一覧ではなく、全体像の把握用。

## 概要
iPhoneのホーム画面に追加して使う筋トレ記録アプリ（PWA）。記録は端末内に保存し、CSVでバックアップ・復元する。

## ディレクトリ構成
| 場所 | 内容 |
|---|---|
| `app/` | アプリ本体（このフォルダをそのまま公開すれば動く） |
| `app/lib.js` | 画面に依存しないロジック（入力チェック、並べ替え、前回記録、CSV変換、タイマー計算） |
| `app/app.js` | 画面の処理（入力、表示、保存、バックアップ） |
| `app/index.html` / `style.css` | 画面の構造と見た目 |
| `app/sw.js` | オフライン起動用のキャッシュ。アプリ更新時は `VERSION` を上げる |
| `app/manifest.webmanifest` / `icon-*.png` | ホーム画面追加用の情報とアイコン |
| `.github/workflows/pages.yml` | main への反映時にテスト → `app/` を GitHub Pages に公開 |
| `tests/` | `lib.js` の単体テスト（`npm test`） |
| `CLAUDE.md` / `docs/` | ルール・作業ログ・設計判断 |

## 主な機能
- 記録（記録タブ）：日付・種目・重量・回数・メモ。種目は最近使った順に候補表示。種目を選ぶと前回の記録を表示し、重量・回数を前回値で自動入力
- 休憩タイマー（記録タブ）：60/90/120秒。一時停止・再開・リセット。記録時の自動スタート（オン/オフ）。終了予定時刻で計算するので画面ロック・再起動でもずれない。状態は localStorage `kintore.v1.timer` に保存
- 履歴（履歴タブ）：日付ごとに折りたたみ表示。各セットを削除可能
- バックアップ（バックアップタブ）：CSVを共有メニュー経由で保存／CSVから読み込み（同じIDは重複追加しない）。7日以上バックアップしていないと記録タブに通知

## データの流れ
入力 → `validateSet`（lib.js）で検証 → localStorage `kintore.v1.sets` に配列で保存 → 画面に表示
バックアップ：`toCsv` → 共有メニュー／ダウンロード。復元：`fromCsv` → `mergeSets` → 保存

## データ形式（1セット）
`{ id, date: "YYYY-MM-DD", exercise, weight: kg(0〜1000, 0.01単位), reps: 整数(1〜1000), note, createdAt: ISO8601 }`
